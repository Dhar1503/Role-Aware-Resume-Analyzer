What the three scores mean

Strength

Measured against criteria for the exact thing you are applying to. A software role weights DSA practice and shipped projects; an M.Tech application weights GATE; civil services weights exam progress and public service. Eligibility rules (age limits, attempts, minimum marks with category relaxations) are reported separately and never folded into the score.

ATS compatibility

Can software read the file? Eighteen checks for multi-column layouts, tables, text boxes, contact details hidden in page headers, scanned pages, unusual section headings, mixed date formats and generic file names. You can see the text exactly as a parser reads it.

Job-description fit

Each requirement in the posting is matched against your resume by meaning, not just keywords, and the matching line is shown as evidence. Requirements that name specific skills are also checked literally, because embeddings alone rate unrelated resumes surprisingly well.
